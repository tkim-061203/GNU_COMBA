Framework Overview
==================

Stage 1: Generation
-------------------
[Natural Language Spec]
       |
       v
[Converter | LLM-Base]
       |
       v
[COMBA XML Specification]
       |
       v
[Generator | LLM-Base]
       |
       v
[Sanitizer | Multi-stage cleanup]
       |
       v
[Generated Verilog Design (GVD)] -> Exits to Stage 2


Stage 2: Verification and Debugging
-----------------------------------
LangGraph State Machine Architecture:

  Row 1 - Syntax Check Loop:
    [Syntax Check: iverilog] -> [Guard-SC] -> [TED-Syntax + EDTM] --+
                                                                    |
                                                                    v
  Row 2 - Testbench Simulation Loop:                           [Debugger
    [TB Sim: iverilog/verilator] -> [Guard-TS] -> [Classify-TB] LLM-LoRA]
    -> [VCD Analyzer] -> [TED-TB] ----------------------------------+

  Feedback path from Debugger:
    Debugger -> Sanitizer -> Syntax Check (rollback / patch / re-sanitize)


Stage 3: Control and Output
---------------------------
Control Mechanisms:
- EDTM deduplication (max 3)
- Guard regression rollback (bad_streak <= 2)
- Self-Consistency Best-of-N (sampling with temperature range 0.0 to 1.0)

Terminal States:
- END_PASS
- END_FAIL_SC
- END_FAIL_TS
- END_MAX_ITER
- END_FAIL_XML

Final Output:
- Verified Verilog Module (.v)


Flow Conventions
----------------
- Solid arrows: Forward data flow
- Dashed/Return arrows: Feedback and rollback loops
- Pipeline Components: LLM nodes, Verification tools, Guard/Control units, Data artifacts
